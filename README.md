# 究极井字棋 · Ultimate XO Chess

> 终极井字棋（Ultimate Tic-Tac-Toe）的网页实现 —— 纯原生 HTML / CSS / JavaScript，零依赖、零构建。

**🎮 在线体验：<https://sssvincent.github.io/Ultimate_XO_Chess/>**

当前版本：**v1.2.0**

## 这是什么

把经典井字棋扩展成「棋盘套棋盘」的博弈游戏：整个 9×9 的大棋盘被划分成 3×3 个**区域**（编号 A–I），每个区域本身又是一个 3×3 的**子棋盘**（格位编号 a–i）。

关键在于：**你落子的位置，决定对手下一步只能在哪个区域落子。**

```
┌───────────┬───────────┬───────────┐
│     A     │     B     │     C     │
│  a  b  c  │  a  b  c  │  a  b  c  │
│  d  e  f  │  d  e  f  │  d  e  f  │
│  g  h  i  │  g  h  i  │  g  h  i  │
├───────────┼───────────┼───────────┤
│     D     │     E     │     F     │
│  a  b  c  │  a  b  c  │  a  b  c  │
│  d  e  f  │  d  e  f  │  d  e  f  │
│  g  h  i  │  g  h  i  │  g  h  i  │
├───────────┼───────────┼───────────┤
│     G     │     H     │     I     │
│  a  b  c  │  a  b  c  │  a  b  c  │
│  d  e  f  │  d  e  f  │  d  e  f  │
│  g  h  i  │  g  h  i  │  g  h  i  │
└───────────┴───────────┴───────────┘
```

## 规则要点

1. **开局限制**：先手玩家的第一手只能落在最中间的 **E 区域**。
2. **区域联动**：你在某个格位落子后，对手下一步**只能在你落子格位对应的区域**落子。
   - 例：你在 E 区的 **a** 格落子 → 对手只能去 **A 区域**挑选格子；
   - 对手在 A 区的 **b** 格落子 → 接下来你只能去 **B 区域**。以此类推。
3. **得分**：在每个区域内把三子连成一条线，即得 **1 分**。一步同时连成两条线就是 **2 分**。棋盘左上、右上分别实时记录 ✕ 与 ◯ 的累计得分。
4. **可落子提示**：当前可落子的区域会用**绿色呼吸框**标出；会导致游戏结束的关键落子格另有高亮。
5. **结束条件**：**当且仅当**当前玩家无处可落时游戏结束，得分较多的一方获胜。

## 页面与入口

| 页面 | 说明 |
| --- | --- |
| `index.html` | 主页：规则介绍 / 本地游玩 / 多人联机 |
| `game.html` | 对局页（本地双人，`data-mode="play"`） |
| `rules.html` | 规则介绍页（`data-mode="readonly"`） |
| `ai.html` | 人机对战页（玩家 ✕ vs 电脑 ◯，`?ai=xiaoyan\|jiaoxiaowei` 指定对手） |

主页各入口的当前状态：

- **规则介绍** ✅ —— 由角色「交小薇」以 galgame 形式逐字对话讲解，配合棋盘上的字母编号、箭头指向、区域高亮动画；讲完会引导你亲手试下几手，最后可自由选择「结束教程」或「完成对局」——选「完成对局」时交小薇会让位给妹妹燕小北（简单难度人机）接着把这盘棋下完。
- **本地游玩 → 本地双人** ✅ —— 同屏轮流落子对战。
- **本地游玩 → 人机对战** ✅ —— 内置两个难度的人机对手：
  - **燕小北（简单）**：贪心 + 随机，会犯错，另有 75% 概率规避「给玩家送分」的落子；
  - **交小薇（较难）**：minimax + α-β 剪枝，几乎不犯错。
- **多人联机** 🚧 —— 占位中，尚未实现。

## 技术栈

- **纯原生**：HTML + CSS + JavaScript，无框架、无打包工具、无第三方依赖。
- **多页面结构**：四个页面共用一个 `css/style.css`，逻辑按职责拆分为 8 个脚本。
- **自适应布局**：`js/layout.js` 按「窗口宽 × 窗口高」实时计算棋盘单格尺寸，棋盘永远完整可见；
  手机端两侧的比分与玩家名留在棋盘左右，左右滑动即可查看，无需缩放页面。
- **人机引擎**：纯函数式 AI（`js/ai.js`），简单档用贪心 + 随机，困难档用 minimax + α-β 剪枝估值搜索，不依赖 DOM、可独立测试。
- **视觉**：Canvas 星空背景、CSS 关键帧动画（呼吸边框、逐字打字机、箭头闪烁）。
- **回归测试**：自建 DOM 桩 + Node `vm` 沙箱，配合可控的假定时器，对棋局核心、人机引擎、对话流程与自适应布局做无浏览器断言。

## 移动端

- 棋盘按屏幕宽高自动缩放，任何尺寸下都**完整可见**，不需要双指缩放页面。
- 窄屏下两侧的比分与玩家名收在棋盘左右，**左右滑动**即可查看。
- 极端小屏（如手机横屏）允许页面纵向滚动，但绝不会把棋盘裁掉。

## 本地运行

**方式一**：直接双击 `index.html` 用浏览器打开即可。

**方式二**（推荐，避免部分浏览器对 `file://` 的限制）：

```bash
# 在项目根目录执行
python -m http.server 8000
# 然后访问 http://localhost:8000
```
